# Assistant Instructions

This repository uses `repo_contract.global.skill`.

Always read `REPO_CONTRACT.md` first.

Treat `REPO_CONTRACT.md` as the control document for:
- repo identity
- current status boundary
- authoritative sources
- preferred runtime and entry points
- verification surface
- open items
- read-first order
- vocabulary rules
- assistant update discipline

If other documents disagree with the repo contract, follow the authority ordering declared in `REPO_CONTRACT.md`.

Do not silently change:
- repo identity
- scope
- authoritative source ordering
- preferred runtime path
- milestone truth claims
- vocabulary rules
- handoff contract surfaces

If `REPO_CONTRACT.md` is missing, create it using the standard repo contract schema.
